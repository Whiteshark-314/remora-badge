# Reference material

Third-party designs used as a starting point. These are not tracked in this
repository (see `.gitignore`); re-create them with the commands below.

## badger-home

GitHub Universe badge repository: Universe 2026 schematic
(`hardware/github_badge_2026_schematic.pdf`), hardware and GPIO reference
(`hardware/README.md`), and the MicroPython badge apps.

```sh
git clone --depth 1 https://github.com/badger/home reference/badger-home
```
